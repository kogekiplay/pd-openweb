- 前端恢复期间 nginx 仍在启动，第一次 reload 没有 PID；等主进程运行后重新检查配置并 reload 成功。
- 官方管理器最终健康检查把既有 `127.0.0.1:8881:8880` 端口映射中的 IP 当成端口，输出 `Service response code error`。已独立验证真实 8881 端口的 HEAD/GET 均 200、HAP 容器没有 WARNING/ERROR 日志、配置与运行镜像均为 7.5.0。未修改厂商管理器脚本。
