# 动态默认值入口严格化

收紧动态默认值组件的入口合同：默认值数字校验器明确接收字符串，动态值主入口的控件列表、动态值数组、回调和组件映射使用有限类型；组件映射改为字符串到 React ComponentType 的记录，避免用索引签名掩盖未知控件类型。`allControls` 和 `onChange` 保留可选兼容，覆盖自定义按钮与快速筛选的轻量调用方。

验证：动态值主入口、配置和组件映射在全仓 strict 下零诊断；表单边界规格通过，fast 类型差分无新增（8,911 原始诊断、2,395 keys），工具链类型门禁 0 条诊断。全仓严格目标继续推进，相关 inputTypes 子组件仍在后续欠债清单中。
