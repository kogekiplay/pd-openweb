# Agent 匿名附件入口

匿名附件入口的文件选择事件、会话 id、附件占位、上传结果、失败回滚、React setter 和按钮 props 已收紧。组件使用泛型附件集合，既保留 ChatPanel/嵌入入口各自的附件额外字段，也要求稳定的 `id` 身份；内部上传占位在边界转换为统一的匿名附件形状，失败索引和验证码取消流程保持原协议。

本批与前一批 Agent SSE 状态翻译层合计移除 96 条严格诊断，按文件/错误码无新增。保留匿名上传的 2 个文件上限、MIME 列表、token→七牛→回填 URL、单文件大小提示和失败占位清理行为。后续继续收紧 agentService 与 AppBuilder 的开放 API 边界。
