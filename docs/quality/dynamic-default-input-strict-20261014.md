# 动态默认值输入组件严格化

动态默认值的通用输入组件、显示组件、子表默认行、来源辅助函数和搜索工作表参数已按真实协议收紧。输入 props、状态、ref、选项/用户/部门/地区/日期/时间/关联记录值均通过有限边界解码；保留动态来源 JSON、空值清除、数值 `0`、布尔 `false` 和空子表行的既有语义。同步修复地区空选择访问末项、数值零被当作空值、自定义子表保存丢失零值/false，以及动态日期和链接参数的回读边界。
