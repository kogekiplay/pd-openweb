- 移动弹层返回栈、事件标记、URL 参数和 hook 使用实际有限签名，history.state 的扩展元信息从 unknown 读取/保留。pushState 失败撤销刚加入的层；history.go 失败恢复栈与待消费标记，并继续抛出原错误，重试不会留下幽灵层或吞掉下一次用户返回。正常父子层、主动关闭、浏览器返回、App URL 与 legacy 空回调行为保持；不新增动态 layerId 或重叠原生回退的时序承诺。

- 通用路径、查询、HTML、字符/文件大小、数值、日期及浏览器工具使用真实输入和返回签名。路由返回的 path 类型明确宽化，不能承诺仍等于原字面量；返回原 cloneDeep 字典，保持共享条目与循环引用，且不修改源配置。HTML 仍直接调用原 toString receiver，日期支持实际 Moment 调用方及原 Q 单位行为，UA 仍保留原正则匹配后比较字面值的规则，重复参数保留数组语义。
- 相关调用方补齐字符串 URL、可缺失条码值、等待 URL ref 和复制值的准确状态类型。没有集成 URL 时不执行复制，DOM 链接先确认 href 存在，移动分享使用 location.href 赋值。二维码预览从空字符串开始，合法 URL 正常更新；缺 URL、坏响应或网络失败使用原错误占位，避免未加载的对象被当作真实二维码内容。
