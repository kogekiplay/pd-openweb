# 移动端子表筛选、列宽与唯一性边界严格化

`src/components/Form/MobileForm/components/ChildTable/utils.ts` 使用具体的行值、列定义、表单规则、错误结果和 SDK 条件合同，移除首版遗留的 any 与类型断言。列宽函数使用泛型保留源列的额外字段与删除列身份，并在测宽失败时清理临时 DOM。

SDK 边界接受 unknown，解码为条件数组；保留历史扁平转分组、日期条件转换、空 min/max 删除及关系 ID 优先级。分组元数据保留，单项条件仍按历史白名单输出；畸形输入明确报错。唯一值比较保留原始数值/字符串身份，支持数值与布尔值，避免把数字 1 和字符串 '1' 当成同值。同步规则循环不再创建无人观察的 rejected Promise；日期范围优先使用校验器返回的错误文案。
