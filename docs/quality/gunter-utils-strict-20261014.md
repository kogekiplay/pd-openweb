# 甘特图工具严格化

## 范围与行为

`src/pages/worksheet/views/GunterView/util.ts` 建立时间轴配置、日历、刻度、记录、分组和时间块的有限模型；动态字段以 `unknown` 读取后验证，去掉记录的开放 `any` 消费、分组断言及非空排序断言。保留额外记录字段、拖拽日期优先级、工作日与普通日期、五种时间粒度、里程碑、选项颜色、未指定分组排序及无匹配索引的 `null` 语义。

- 修复 `SpeedCreateTime` 的里程碑日刻度辅助路径：工作日分支完整传入中心日期与视图配置，避免解构缺失配置时抛错。
- `updateEditIndex` 如实接收数值位置、记录 ID 和 `null`；搜索未命中仍按旧有 `null * 32 === 0` 语义定位。
- 无效时间粒度回退到日视图；工作日计数拒绝非整数、非有限数、无效日期及一周全部休息的配置，避免循环无法结束。
- 年粒度改用 Moment 声明支持的 `year` 名称，与旧的 `Y` 运行时行为一致；保留日期颜色、宽度及主题默认值，不增加样式基线。
