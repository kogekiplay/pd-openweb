## 实现与运行边界

- 表单筛选、规则五类映射桶、动态赋值及行级规则适配使用有限模型；返回值如实保留 boolean/string/number/undefined（地区 HASVALUE 返回代码）。筛选值先捕获 unknown，再按文本、数值、日期、人员/部门/关联等分支读取；无效集合不会因被当成空数组而错误匹配“不等于/为空”。真实日期单位和排序行为保持，未借类型修改旧算法。
- 启动元数据只声明和验证本入口实际读取的账号、部署配置、组织译名及窗口配置字段；其他元信息保留。页面包装器保留原组件 props 类型，memo/forwardRef 可用，公开入口哨兵继续同步初始化。网络失败、响应字段错误及初始元数据同步异常都显示错误/刷新入口，业务组件不会在失败后读取旧身份数据。组织 ID 缺失时不发权限预热请求，未生成权限默认值。
- 应用语言、缓存索引、描述生成和文件 URL 使用实际模型。语言请求失败会拒绝 Promise，跨应用预热仍捕获失败回退原文；同数组同长度索引命中保持常数时间，只有建立索引时验证整个包。描述成功/失败载荷分开处理。缺图标 URL 不发请求，缺颜色保留原 SVG，正常图标转换保持一致。
- 关联记录计数、关联格式化、草稿保存/还原使用递归 JSON 值与有限记录模型，类型边界不再被 ControlValue 的 any 掩盖。保留数值标题、日期 JSON ISO 格式和有效原字段；损坏嵌套 sourcevalue 按原错误路径删除，不将函数当记录值。
- 高级设置区分原始字符串设置、固定 JSON 键协议和动态未知键。模型覆盖数值、字段列表、选项文字/颜色、图标、动态源以及组件实际读取的事件/筛选/请求/响应/样式配置；动态键在消费前验证。缺省和解析失败的 `''` 保留，日期 min/max 的动态源、国家对象/地区字符串、评分数字静态值保留。临时日历和导航数组有独立解析模型，不改变服务端字符串格式。
- 实际评分组件保存 `staticValue:5`，此前表单默认源解码器只接受字符串，导致默认值丢失。本批补数值协议并只在评分控件读取数值。真实生产者 → 配置序列化 → getDynamicValue 输出 `'5'` 通过，旧解码器在同一规格中失败；数值 0 保留原有空值行为，字符串 `'0'` 保持有效，人员等控件不会误用数字评分载荷。
